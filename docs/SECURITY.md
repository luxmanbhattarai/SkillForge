# Security

The security policy for SkillForge lives in the root
[`SECURITY.md`](../SECURITY.md).

In short: report vulnerabilities privately via a GitHub security
advisory on
[luxmanbhattarai/SkillForge](https://github.com/luxmanbhattarai/SkillForge) —
never in a public issue. The repository runs an automated credential and
prompt-injection scan (`npm run check:security`) on every push, pull
request, and weekly via CI.
