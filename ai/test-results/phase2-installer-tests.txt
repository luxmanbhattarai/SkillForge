Bugs found and fixed during testing
-----------------------------------
  1. resolveLocations crashed on targets whose legacySkills
     segments are null (claude-code, cursor). Fixed in
     scripts/install/installer.mjs.
  2. doctor called scanSkillDirs' isSymlink boolean as a
     function. Fixed in scripts/install/commands.mjs.
  3. askChoice resolved null for every answer: rl.close() was
     called before resolve(), and the 'close' handler (EOF case)
     settled the promise first. Fixed in
     scripts/install/prompt.mjs (resolve before close; one shared
     readline interface per run so batched answers are not lost).
  4. Refusal/failure lines were printed twice (inline + summary).
     Summary detail lines removed.
  5. ENOTDIR (destination blocked by a file) crashed install
     instead of failing the item cleanly. lstatOrNull,
     readManifest, and directory scans now treat ENOTDIR like
     "does not exist"; the item fails with a clear message and
     nothing is half-installed.
  6. `node --test test/` does not scan the directory on Node
     v24.22.1 (treats it as a test file; MODULE_NOT_FOUND).
     `npm test` uses bare `node --test` instead; see
     ai/decisions/2026-11-20-installer-test-command.md.
