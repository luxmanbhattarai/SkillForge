## Notable corrections (cross-skill)

1. **Prisma version claims were the most seriously wrong content in the batch.** The skill presented Prisma ORM 8 as the stable default and Prisma 6 as still supported; in reality Prisma 8 is a release candidate with a rewritten API and Prisma 6 lost support on 19 November 2026. The skill is now explicitly a Prisma ORM 7 skill, with the 8 RC warning and version pinning. The `$use` middleware recommendation and the adapter-less `new PrismaClient()` example were also wrong for Prisma 7 and are fixed.
2. **PostgreSQL JSONB example taught a non-working index.** A GIN index on a `->` expression cannot serve a `->>` text-equality query; the example would have produced a sequential scan while appearing to be indexed.
3. **MySQL upsert example used deprecated syntax.** `VALUES(col)` in `ON DUPLICATE KEY UPDATE` has been deprecated since MySQL 8.0.20; the row-alias form is the current syntax.
4. **Transactions stated the wrong default isolation level for MySQL.** MySQL/InnoDB defaults to REPEATABLE READ, not READ COMMITTED.
5. **Database-security RLS example could break queries** when the tenant setting was unset, and its grant example silently missed future tables.
